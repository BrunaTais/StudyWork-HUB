## Objetivo do Software
O StudyWork Hub é um aplicativo desktop desenvolvido para auxiliar estudantes na organização de sua rotina acadêmica. O software centraliza o gerenciamento de tarefas pendentes, o armazenamento de referências a materiais de estudo e o planejamento de horários e disciplinas.

## Funcionalidades do Sistema (Requisitos)
- **Gerenciamento de Usuários:** Tela de autenticação e suporte a perfil de usuário.
- **Controle de Tarefas:** Cadastro, listagem e acompanhamento de status de tarefas diretamente integrados ao banco de dados MySQL.
- **Organização de Materiais:** Cadastro e visualização de caminhos de arquivos e materiais de apoio.
- **Plano de Estudos:** Criação e cronograma de horários e objetivos por disciplina.
- **Painel Geral (Dashboard):** Indicadores visuais em tempo real com o resumo das atividades pendentes, materiais e planos cadastrados.
